## 🎨 Personnalisation

### Changer le thème
Le portfolio s'ouvre en **mode clair** par défaut. Pour changer :
- Modifier la classe `light-mode` dans `<body>` (ligne 47 de index.html)
- Ou utiliser le toggle de thème dans l'interface

### Modifier les couleurs
Les couleurs sont définies dans `:root` du fichier `style.css` :
```css
--color-purple: #8000ff;
--color-light-blue: #6bc5f8;
--color-light-purple: #cf59e6;
```

### Ajouter un projet
1. Ajouter l'image dans `src/images/`
2. Copier un bloc `project-box-wrapper` dans `index.html`
3. Modifier le contenu (titre, description, lien, image)
